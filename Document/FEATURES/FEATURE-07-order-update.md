# FEATURE-07: 주문 수정 (Order Update)

## 기능 목적

사용자가 기존 주문의 상태 및 생산 관련 정보를 수정하고 JSON 파일에 반영할 수 있도록 한다.

---

## 사용자 시나리오

1. 사용자가 주문 수정 메뉴를 선택한다.
2. 사용자가 수정할 주문번호를 입력한다.
3. 시스템이 현재 주문 정보를 표시한다.
4. 사용자가 변경할 항목(상태, 생산 관련 필드)을 입력한다.
5. 시스템이 변경 내용을 저장하고 수정 완료 메시지를 표시한다.
6. 프로그램을 재시작해도 수정된 값이 유지된다.

---

## 입력

| 항목 | 타입 | 제약 |
|------|------|------|
| 주문번호 | 문자열 | 필수 |
| 주문 상태 | 문자열 | RESERVED / REJECTED / PRODUCING / CONFIRMED / RELEASE 중 하나 |
| 실제 생산 수량 | 정수 | 0 이상, PRODUCING 이후 상태에서 설정 가능 |
| 생산 시작 시간 | 문자열 (ISO 8601) | PRODUCING 이후 상태에서 설정 가능 |
| 총 생산 시간 | 실수 (min) | 0 초과, PRODUCING 이후 상태에서 설정 가능 |

- 입력하지 않은 항목은 기존 값을 유지한다.

---

## 출력

- 성공 시: 수정 완료 안내 및 수정된 주문 정보 표시
- 실패 시: 오류 안내 메시지 표시

---

## 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 존재하지 않는 주문번호 | 오류 안내 메시지 표시 |
| 유효하지 않은 상태값 입력 | 오류 안내 후 재입력 유도 |
| 실제 생산 수량이 음수 | 오류 안내 후 재입력 유도 |
| 총 생산 시간이 0 이하 | 오류 안내 후 재입력 유도 |
