# FEATURE-04: 시료 삭제 (Sample Delete)

## 기능 목적

사용자가 등록된 시료를 시스템에서 삭제하고 JSON 파일에서도 제거할 수 있도록 한다.

---

## 사용자 시나리오

1. 사용자가 시료 삭제 메뉴를 선택하고 삭제할 시료 ID를 입력한다.
2. 시스템이 해당 시료 정보를 표시하고 삭제 여부를 재확인한다.
3. 사용자가 삭제를 확인하면 시스템이 해당 시료를 제거하고 완료 메시지를 표시한다.
4. 프로그램을 재시작해도 삭제된 시료는 복원되지 않는다.

---

## 입력

| 항목 | 타입 | 제약 |
|------|------|------|
| 시료 ID | 문자열 | 필수, 기존에 등록된 ID |
| 삭제 확인 | Y/N | 최종 확인용 |

---

## 출력

- 성공 시: 삭제 완료 안내 메시지 표시
- 취소 시: 취소 안내 메시지 표시 후 메뉴로 복귀
- 실패 시: 오류 안내 메시지 표시

---

## 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 존재하지 않는 ID 입력 | 오류 안내 후 재입력 유도 |
| 사용자가 삭제 확인에서 N 입력 | 삭제 취소 안내 후 메뉴로 복귀 |
