# FEATURE-08: 주문 삭제 (Order Delete)

## 기능 목적

사용자가 특정 주문을 시스템에서 삭제하고 JSON 파일에 반영할 수 있도록 한다.

---

## 사용자 시나리오

1. 사용자가 주문 삭제 메뉴를 선택한다.
2. 사용자가 삭제할 주문번호를 입력한다.
3. 시스템이 해당 주문 정보를 표시하고 삭제 여부를 확인한다.
4. 사용자가 삭제를 확인하면 시스템이 해당 주문을 삭제하고 완료 메시지를 표시한다.
5. 프로그램을 재시작해도 삭제된 주문은 복원되지 않는다.

---

## 입력

| 항목 | 타입 | 제약 |
|------|------|------|
| 주문번호 | 문자열 | 필수 |
| 삭제 확인 | Y/N | 필수 |

---

## 출력

- 성공 시: 삭제 완료 안내 메시지
- 취소 시: 삭제 취소 안내 메시지
- 실패 시: 오류 안내 메시지 표시

---

## 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 존재하지 않는 주문번호 | 오류 안내 메시지 표시 |
| 사용자가 삭제 취소 (N 입력) | 삭제하지 않고 취소 안내 메시지 표시 |
