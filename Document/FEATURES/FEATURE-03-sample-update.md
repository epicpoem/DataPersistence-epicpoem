# FEATURE-03: 시료 수정 (Sample Update)

## 기능 목적

사용자가 기존에 등록된 시료의 속성을 수정하고 변경 내용을 JSON 파일에 반영할 수 있도록 한다.

---

## 사용자 시나리오

1. 사용자가 시료 수정 메뉴를 선택하고 수정할 시료 ID를 입력한다.
2. 시스템이 현재 저장된 해당 시료의 정보를 표시한다.
3. 사용자가 수정할 항목을 선택하고 새 값을 입력한다.
4. 시스템이 변경 내용을 저장하고 수정 완료 메시지를 표시한다.
5. 프로그램을 재시작해도 수정된 값이 유지된다.

---

## 입력

| 항목 | 타입 | 제약 |
|------|------|------|
| 시료 ID | 문자열 | 필수, 기존에 등록된 ID |
| 수정할 항목 값 | 항목별 타입 | 해당 항목의 유효 범위 준수 |

수정 가능한 항목:
- 시료 이름
- 평균 생산시간 (0 초과)
- 수율 (0.0 초과 ~ 1.0 이하)
- 재고 (0 이상)

---

## 출력

- 성공 시: 수정 완료 안내 및 수정된 시료 정보 표시
- 실패 시: 오류 안내 메시지 표시

---

## 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 존재하지 않는 ID 입력 | 오류 안내 후 재입력 유도 |
| 수정 값이 유효 범위 벗어남 | 오류 안내 후 재입력 유도 |
