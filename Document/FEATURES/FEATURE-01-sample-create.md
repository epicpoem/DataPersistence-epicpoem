# FEATURE-01: 시료 등록 (Sample Create)

## 기능 목적

사용자가 새로운 시료를 시스템에 등록하고 JSON 파일에 영구 저장할 수 있도록 한다.

---

## 사용자 시나리오

1. 사용자가 시료 등록 메뉴를 선택한다.
2. 사용자는 아래 항목을 순서대로 입력한다.
   - 시료 ID (예: `S-001`)
   - 시료 이름 (예: `실리콘 웨이퍼-8인치`)
   - 평균 생산시간 (min/ea, 예: `0.5`)
   - 수율 (0.0 ~ 1.0, 예: `0.92`)
3. 시스템이 입력 내용을 저장하고 등록 완료 메시지를 표시한다.
4. 프로그램을 종료하고 재시작해도 등록한 시료가 유지된다.

---

## 입력

| 항목 | 타입 | 제약 |
|------|------|------|
| 시료 ID | 문자열 | 필수, 시스템 내 고유 |
| 시료 이름 | 문자열 | 필수 |
| 평균 생산시간 | 실수 | 필수, 0 초과 |
| 수율 | 실수 | 필수, 0.0 초과 ~ 1.0 이하 |

- 재고(stock)는 시스템이 자동으로 0으로 초기화한다.

---

## 출력

- 성공 시: 등록 완료 안내 및 등록된 시료 정보 요약 표시
- 실패 시: 오류 안내 메시지 표시

---

## 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 이미 존재하는 ID 입력 | 오류 안내 후 재입력 유도 |
| 필수 항목 미입력 | 오류 안내 후 재입력 유도 |
| 수율이 범위(0.0~1.0) 벗어남 | 오류 안내 후 재입력 유도 |
| 평균 생산시간이 0 이하 | 오류 안내 후 재입력 유도 |
