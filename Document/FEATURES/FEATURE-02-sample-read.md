# FEATURE-02: 시료 조회 (Sample Read)

## 기능 목적

사용자가 등록된 시료를 전체 목록 또는 개별 단건으로 조회할 수 있도록 한다.  
프로그램 재시작 후에도 이전에 저장된 데이터를 불러올 수 있어야 한다.

---

## 사용자 시나리오

### 시나리오 A: 전체 목록 조회

1. 사용자가 시료 전체 조회 메뉴를 선택한다.
2. 시스템이 JSON 파일에서 데이터를 불러와 전체 시료 목록을 표시한다.
3. 등록된 시료가 없을 경우 해당 안내 메시지를 표시한다.

### 시나리오 B: 단건 조회

1. 사용자가 단건 조회 메뉴를 선택하고 시료 ID를 입력한다.
2. 시스템이 해당 ID의 시료 상세 정보를 표시한다.
3. 해당 ID가 없을 경우 안내 메시지를 표시한다.

---

## 입력

| 항목 | 타입 | 비고 |
|------|------|------|
| 시료 ID | 문자열 | 단건 조회 시에만 필요 |

---

## 출력

### 전체 목록 조회
각 시료의 아래 정보를 목록 형식으로 표시:
- 시료 ID, 이름, 평균 생산시간, 수율, 현재 재고

### 단건 조회
해당 시료의 모든 속성 상세 표시:
- 시료 ID, 이름, 평균 생산시간, 수율, 현재 재고

---

## 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 등록된 시료가 없음 | "등록된 시료가 없습니다" 안내 |
| 존재하지 않는 ID로 단건 조회 | "해당 시료를 찾을 수 없습니다" 안내 |
