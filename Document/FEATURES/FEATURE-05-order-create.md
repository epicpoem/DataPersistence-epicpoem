# FEATURE-05: 주문 등록 (Order Create)

## 기능 목적

사용자가 새로운 주문을 시스템에 등록하고 JSON 파일에 영구 저장할 수 있도록 한다.

---

## 사용자 시나리오

1. 사용자가 주문 등록 메뉴를 선택한다.
2. 사용자는 아래 항목을 순서대로 입력한다.
   - 시료 ID (예: `S-001`)
   - 고객명 (예: `삼성전자 파운드리`)
   - 주문 수량 (ea, 예: `200`)
3. 시스템이 주문번호를 자동 생성하고 (예: `ORD-20260416-0001`) 초기 상태를 RESERVED로 설정한다.
4. 시스템이 입력 내용을 저장하고 등록 완료 메시지와 함께 주문번호를 표시한다.
5. 프로그램을 종료하고 재시작해도 등록한 주문이 유지된다.

---

## 입력

| 항목 | 타입 | 제약 |
|------|------|------|
| 시료 ID | 문자열 | 필수 |
| 고객명 | 문자열 | 필수 |
| 주문 수량 | 정수 | 필수, 1 이상 |

- 주문번호는 시스템이 자동 생성한다. 형식: `ORD-{날짜(YYYYMMDD)}-{날짜별 순번 4자리}`
- 초기 주문 상태는 시스템이 자동으로 RESERVED로 설정한다.
- 생산 관련 필드(실생산량, 생산 시작 시간, 총 생산 시간)는 초기값으로 설정된다.

---

## 출력

- 성공 시: 등록 완료 안내 및 생성된 주문번호, 주문 정보 요약 표시
- 실패 시: 오류 안내 메시지 표시

---

## 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 필수 항목 미입력 | 오류 안내 후 재입력 유도 |
| 주문 수량이 1 미만 | 오류 안내 후 재입력 유도 |
