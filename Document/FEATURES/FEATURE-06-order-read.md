# FEATURE-06: 주문 조회 (Order Read)

## 기능 목적

사용자가 저장된 주문 정보를 전체 목록 또는 단건으로 조회할 수 있도록 한다.

---

## 사용자 시나리오

### 전체 조회
1. 사용자가 주문 전체 조회 메뉴를 선택한다.
2. 시스템이 저장된 모든 주문 목록을 표시한다.
3. 주문이 없는 경우 "등록된 주문이 없습니다" 메시지를 표시한다.

### 단건 조회
1. 사용자가 주문 단건 조회 메뉴를 선택한다.
2. 사용자가 조회할 주문번호를 입력한다.
3. 시스템이 해당 주문의 상세 정보를 표시한다.
4. 존재하지 않는 주문번호 입력 시 오류 안내를 표시한다.

---

## 입력

| 항목 | 타입 | 제약 |
|------|------|------|
| 주문번호 (단건 조회 시) | 문자열 | 필수 |

---

## 출력

### 전체 조회 출력 항목
각 주문마다 아래 항목 표시:
- 주문번호
- 시료 ID
- 고객명
- 주문 수량
- 주문 상태

### 단건 조회 출력 항목
- 주문번호
- 시료 ID
- 고객명
- 주문 수량
- 주문 상태
- 실제 생산 수량 (PRODUCING/CONFIRMED/RELEASE 상태인 경우)
- 생산 시작 시간 (PRODUCING/CONFIRMED/RELEASE 상태인 경우)
- 총 생산 시간 (PRODUCING/CONFIRMED/RELEASE 상태인 경우)

---

## 예외 처리

| 상황 | 처리 방식 |
|------|-----------|
| 등록된 주문이 없음 (전체 조회) | "등록된 주문이 없습니다" 안내 |
| 존재하지 않는 주문번호 (단건 조회) | 오류 안내 메시지 표시 |
